개인정보처리방침

기록은 당신의 기기와 개인 iCloud에.

앱의 데이터 수집

Dayroad 1.0은 개발자 서버를 운영하지 않으며, 앱의 사용자 데이터를 개발자 또는 광고·분석 사업자에게 자동 전송하지 않습니다. 광고, 사용자 추적, 외부 분석·진단 SDK를 사용하지 않습니다. 앱 데이터가 기기를 벗어나지 않는다는 뜻은 아닙니다. 개인 iCloud 동기화와 사용자가 선택한 백업 저장에는 Apple 또는 해당 저장 서비스가 사용됩니다.

기기에 저장하는 데이터

집중 기록과 누적 집중시간, Stamp, Home 성장 상태, 꾸미기·이름 설정 및 앱 설정을 기기에 저장해 기능을 제공합니다. 누적 75분 무료 체험 사용량은 기기의 Keychain에 별도로 저장하며, iCloud 동기화나 JSON 백업에 포함하지 않습니다. 구매 권한도 성장 기록과 별도로 관리합니다.

개인 iCloud 동기화

iCloud를 사용할 수 있는 환경에서는 집중 기록, Stamp, Home 성장 및 일부 설정을 사용자의 개인 CloudKit 데이터베이스에 저장하고 같은 iCloud 계정의 기기 사이에서 자동 동기화합니다. 공개 데이터베이스나 개발자 서버로 전송하지 않으며 개발자는 이 개인 데이터베이스의 기록을 열람할 수 없습니다. 계정 변경을 구분하기 위한 식별값은 해시 처리해 기기에 보관합니다. iCloud의 저장·전송에는 Apple의 서비스 및 개인정보 보호 정책이 적용됩니다.

JSON 백업

사용자가 내보내기를 선택하면 기록·성장·꾸미기·일부 설정이 포함된 JSON 파일을 생성하고, 사용자가 고른 파일 저장 위치에 보관합니다. 가져오기는 사용자가 선택한 백업을 읽어 기록을 병합하고 해당 설정을 적용합니다. 구매 권한과 무료 체험 사용량은 백업으로 복구하거나 변경하지 않습니다. 파일을 외부 저장 서비스에 저장하거나 공유하면 해당 서비스의 정책이 적용됩니다. 백업에는 개인 기록이 포함되므로 안전하게 보관해 주세요.

App Store 구매

집중 드라이브 이용권은 StoreKit을 사용하는 비소모성 일회성 구매이며 구독이 아닙니다. Apple이 결제와 구매 기록을 처리하고, 앱은 검증된 거래 정보로 이용 권한을 확인합니다. 개발자는 카드 번호나 Apple 계정 비밀번호를 받지 않으며, 앱에서 구매 정보를 개발자 서버나 외부 분석 서비스로 전송하지 않습니다. 구매 복원은 이용 권한 확인 기능이며 집중 기록 복구 기능과는 별개입니다.

Focus Lock·알림·잠금화면

Focus Lock은 사용자가 허용한 Apple의 스크린 타임 기능으로 선택한 앱 등의 접근을 집중 중 제한합니다. 선택 항목은 Apple이 제공하는 토큰 형태로 기기 및 앱 확장 간에 저장·사용하며 개발자에게 전송하지 않습니다. 알림과 Live Activity는 집중·휴식 상태를 기기에서 표시하기 위해 사용합니다. 잠금화면에는 타이머나 완료 메시지가 보일 수 있습니다. 관련 권한은 기기 설정에서 관리할 수 있습니다.

데이터 관리와 삭제

설정의 데이터·백업 화면에서 JSON 내보내기·가져오기와 데이터 삭제를 관리할 수 있습니다. 삭제 전 화면에 표시되는 범위와 iCloud 안내를 확인하고 필요한 백업을 보관해 주세요. 앱의 데이터 삭제는 Apple 구매 기록을 취소하지 않으며 무료 체험 사용량을 초기화하지 않습니다. 사용자가 별도로 내보낸 파일은 저장한 위치에서 직접 관리·삭제해야 합니다. 개발자는 사용자의 개인 iCloud나 로컬 기록을 대신 복구하거나 삭제할 수 없습니다.

문의와 이 안내 사이트

이메일로 문의하면 이메일 주소와 직접 보내주신 내용은 문의 응대에 사용됩니다. 비밀번호·결제수단 정보·전체 백업 파일은 보내지 마세요. 이 안내 사이트에는 광고·분석 도구나 추적 스크립트를 넣지 않았습니다. 사이트는 GitHub Pages에 호스팅되며 GitHub가 보안·서비스 운영을 위해 IP 주소 등의 기술 정보를 처리할 수 있습니다. 이는 Dayroad 앱의 데이터 수집과 구분됩니다.
